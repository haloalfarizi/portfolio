# Portfolio — Alfarizi

Website portfolio personal dan branding modern untuk software engineer & creative developer.

## 🛠️ Tech Stack

- **Framework**: [Astro](https://astro.build)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) with `@astrojs/react`
- **Analytics**: [Plausible Analytics](https://plausible.io) (privacy-friendly, no-cookie)

## 📁 Struktur Halaman & Fitur

- `/` — Landing page with Hero animation, featured projects showcase, and CTA
- `/about` — Bio, core technical skills, and experience journey
- `/projects` — Grid of selected projects with live demo and GitHub links
- `/contact` — Contact details & interactive inquiry form

## 🚀 Menjalankan Project

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
